# Guides

- `commun/` : ce qui vaut pour tout Linux — [compiler namfoop](commun/compiler.md), [ranger la bibliothèque](commun/bibliotheque.md),
  comprendre les réglages temps réel, jouer en plein écran sans bureau (cage + foot).
- `pi5-dietpi/` : le Raspberry Pi 5 de scène, sous DietPi, de la carte SD au premier
  son.
- `endeavouros/` : le PC sous EndeavourOS (et Arch), mode scène et PREEMPT_RT en
  option.

Chaque guide se lit dans l'ordre et se termine par une vérification qu'on peut refaire seul.
